# グラフ探検室

中学1年の比例・反比例、中学2年の一次関数、中学3年の二次関数 `y=ax²` を、グラフ操作で学ぶ依存関係なしの静的Webアプリです。

## ローカルで確認

`index.html` をブラウザで開くか、任意の静的ホスティングへそのまま配置してください。ビルドツールやインストールは不要です。

## 公開

GitHub Pages、Vercel、Netlifyなどで、ルートディレクトリをそのまま公開できます。Vercelでは Framework Preset を `Other`、Build Command を空欄、Output Directory を `.` に設定します。

## MVPの内容

- 単元切り替え：比例・反比例／一次関数／二次関数
- 係数 `a`、切片 `b` のスライダーと式・グラフの連動
- 反比例グラフの表示切り替え
- グラフ上のドラッグによる座標読み取り
- 傾き・切片・放物線の見方を説明するガイド
- 中1〜中3の3問クイズと即時解説
- スマートフォン向けレスポンシブレイアウト
